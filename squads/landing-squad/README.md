# Landing Squad

Squad especializado na criação e otimização de landing pages de alto impacto e alta conversão.

## Agentes

| Agente | Especialidade | Quando Usar |
|--------|--------------|-------------|
| **landing-chief** | Orquestrador & Estratégia de Conversão | Ponto de entrada — coordena tudo |
| **peep-laja** | CRO (CXL/Wynter) | Pesquisa, diagnóstico, programa de CRO |
| **oli-gardner** | Landing Page Architecture (Unbounce) | Estrutura, seções, Attention Ratio |
| **michael-aagaard** | CTA & Microcopy | CTAs, formulários, copy de decisão |
| **cro-specialist** | A/B Testing & Analytics | Testes, dados, significância estatística |
| **performance-engineer** | Core Web Vitals & Speed | Velocidade, LCP, CLS, mobile |
| **funnel-architect** | Funil & Jornada do Visitante | Awareness, pós-conversão, retargeting |

## Como Usar

### Construir uma nova landing page
```
/landing-squad build [descrição do projeto]
```
→ Aciona: landing-chief → funnel-architect → oli-gardner → copy → design → performance → tracking

### Auditar landing page existente
```
/landing-squad audit [URL ou descrição]
```
→ Aciona: peep-laja → cro-specialist → oli-gardner → performance-engineer

### Otimizar CTA e copy de decisão
```
/landing-squad optimize-cta [contexto]
```
→ Aciona: michael-aagaard → cro-specialist

### Sprint de CRO
```
/landing-squad cro-sprint [página + dados disponíveis]
```
→ Workflow completo de 4 semanas

## Integrações com Outros Squads

- **copy-squad** → Para copy principal longa e headlines de campanha
- **design-squad** → Para UI/UX e design system
- **traffic-masters** → Para message match com criativos de tráfego pago
- **hormozi-squad** → Para construção de oferta irresistível
- **data-squad** → Para setup de analytics e interpretação de dados

## Princípios do Squad

1. Uma página, um objetivo. Sempre.
2. Message match é obrigatório — anúncio e página falam a mesma língua.
3. Performance é conversão — página lenta é página que não converte.
4. Dados primeiro, opiniões depois.
5. Teste uma variável por vez. Sempre.
6. Nível de consciência do tráfego determina tudo.
